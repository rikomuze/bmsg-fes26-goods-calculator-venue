# BMSG FES’26 当日グッズ計算機

BMSG FES’26 公演当日のグッズ販売（FES公式グッズ・アーティストグッズ・MEGA CAPSULE）の購入予定を入れると、合計金額・合計点数・内訳を自動で計算できる非公式ファンメイドツールです。

公開ページ: https://rikomuze.github.io/bmsg-fes26-goods-calculator-venue/

- 商品情報は公式の告知（https://bmsgfes.tokyo/news/261001_2）の画像をもとに入力しています。
- BMSG公式とは関係ありません。価格・購入制限は購入前に必ず公式ページをご確認ください。
